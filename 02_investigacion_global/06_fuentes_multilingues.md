## 2. Buscadores Meta-Científicos Abiertos con API Gratuita

Para automatizar búsquedas sin muros de pago ni bloqueos:
1. **NASA ADS (`ui.adsabs.harvard.edu` + API REST):** Indexa **todos** los resúmenes de la *Lunar and Planetary Science Conference (LPSC)* desde 1970, *Icarus*, *JGR Planets*, *Planetary and Space Science* y *Astrobiology*.
2. **OpenAlex (`api.openalex.org`):** Catálogo abierto mundial de $>250\text{ millones}$ de artículos científicos multilingües sin necesidad de API key pesada, filtrable por concepto, idioma, institución y coordenadas en el resumen.
3. **Semantic Scholar API (`api.semanticscholar.org`)** y **arXiv API (`export.arxiv.org` — `astro-ph.EP`, `physics.geo-ph`)**.
4. **PANGAEA (`pangaea.de`):** Repositorio mundial abierto de datos geocientíficos de campo con coordenadas GPS exactas de perforaciones polares, Antártida, Atacama y océanos.

## 3. Protocolo de Extracción Estructurada para el Equipo / Agente Scout

Cada vez que consultemos un paper en cualquier idioma, extraemos siempre la misma ficha JSON/Markdown estandarizada:
- `site_name` (nombre local + nombre internacional)
- `coordinates` (`lat`, `lon`, `elevation_m`)
- `target_body_archetype` (`L1`, `L2`, `L3`, `M1`, `M2`, `M3`, `M4`)
- `matched_parameters` (ej. mineralogía XRD, $T_{\text{min}}$, profundidad de hielo, diámetro de tubo)
- `unmatched_limitations` (ej. lluvia estacional, vegetación dispersa)
- `citation` (autor, año, idioma original, DOI / URL abierta)
